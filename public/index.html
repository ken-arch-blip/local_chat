#

Text channels

Organise the noise. Create as many channels as you like, delete the ones that go quiet. Messages arrive over a websocket the instant they're sent.

◉

Voice rooms

Hop into a voice channel and talk. Peer-to-peer WebRTC, so your audio doesn't detour through anyone's datacentre. Mute, deafen, and a ring around whoever's talking.

✎

Edit & delete

Fix the typo instead of living with it. Edits are marked, deletions leave a tombstone, and server owners can clear up anything.

☺

Reactions & replies

React with an emoji, or reply inline so a thread of eight people stays readable. Both update live for everyone in the channel.

@

Direct messages

Pull someone aside without leaving the app. DMs are their own channels, ordered by whoever spoke last.

⌘

Invite codes

Every server gets a code. Hand it to a friend, they're in. Hand it to nobody, and nobody's in.

01

Make a server

One click. You get a #general, a #random, and a General voice room to start with — rename or bin them as you like.

02

Share the code

An eight-character invite code appears in the server header. That code is the entire door policy.

03

Talk

Type, react, reply, or drop into voice. Everything syncs live to everyone who's online.

It runs on your box.

Huddle is a single Node process and a SQLite file. Deploy it to Render, a Raspberry Pi, or a laptop in a cupboard. There is no company in the middle, no telemetry, and no plan that gets worse next quarter.
